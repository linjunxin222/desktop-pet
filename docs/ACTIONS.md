# 动作规格（ACTIONS）

> 参照：桌面宠物「狐娘」同款做法。**不是 Live2D**，而是
> 「每个动作生成一段视频 → 抽帧 → 透明 PNG 序列 → 状态机 + 物理」。
> 帧由程序按方向镜像，所以只需要做「朝右」一套。

## 1. 帧规格

| 项 | 值 |
|---|---|
| 画布 | **256 × 256**，透明底，人物居中偏下（脚底距底边约 12px） |
| 人物高度 | 约 190–210px（占画布 75%–82%） |
| 方向 | **只做朝右**，朝左由程序水平翻转 |
| 帧率 | 8–12 fps 足够；每状态 6–16 帧 |
| 命名 | `assets/actions/<state>/<state>_00.png` … |
| 背景 | 纯白 `#FFFFFF`（生成时白底，导入时自动抠掉） |

## 2. 八个状态

| 状态 | 目录 | 帧数 | 说明 |
|---|---|---|---|
| 待机 | `idle` | 8–12 | 呼吸、眨眼、偶尔张望；可循环 |
| 行走 | `walk` | 8–12 | 朝右走，脚要离地，重心上下起伏 |
| 坐下 | `sit` | 6–8 | 坐在地上，腿收起来；落地后偶尔触发 |
| 开心 | `happy` | 8–12 | 原地小跳或转圈；被点击时触发 |
| 下落 | `fall` | 4–6 | 手脚张开、头发向上；循环播放 |
| 拖拽 | `drag` | 4–6 | 被拎起来、手脚垂下；循环 |
| 爬墙 | `climb` | 8–12 | 贴着墙往上爬，朝右（墙面在右手边） |
| 倒挂 | `crawl` | 8–12 | 倒挂在屏幕顶边，朝右**水平移动**，身子是倒的 |

## 3. 生成提示词（每个状态一条）

统一前缀：

```
日系 chibi 全身立绘动画帧，2 头身，红发红眼，白色和风长袍 + 红色内衬 + 黑缎带 + 金色流苏，
头顶一只小黄鸭，粗深色描边，平涂 + 软阴影，纯白背景，正面偏右 3/4 侧身，全身完整，不裁切
```

各状态追加：

| 状态 | 追加描述 |
|---|---|
| idle | 自然站立，轻微呼吸起伏，手臂自然下垂，循环 |
| walk | 朝右侧行走的循环，手臂前后摆动，脚交替抬起 |
| sit | 坐在地上，双腿侧收，手撑地，抬头看镜头 |
| happy | 原地开心跳起两次，双手举起，循环 |
| fall | 从空中下落，手臂上扬、头发向上飘，循环 |
| drag | 被拎住后颈悬空，四肢自然垂下，身体轻微摆动，循环 |
| climb | 贴着右侧墙面向上爬，四肢张开抓墙 |
| crawl | 倒挂在天花板上向右移动，身体完全倒置 |

**关键要求**（视频里踩过的坑）：
1. **首帧和尾帧用同一张图**，否则循环会跳；
2. **头顶多留空间**，不然耳朵/鸭子被裁掉；
3. 动作幅度宁小勿大，尾巴/头发别像翅膀一样乱飞；
4. 一次只生成**一个动作**，不要一条视频里塞多个动作。

## 4. 状态机与物理

```
                ┌──────────── happy ◀── 点击
                │
 idle ──随机──▶ walk ──碰左右墙──▶ climb ──到顶──▶ crawl
   ▲                                               │
   │                                               ├──到尽头──▶ fall
   └──────────── 落地/坐下 ◀── fall ◀───────────────┘
                ▲
              drag（按住拖动）──松手──▶ fall
```

- **地面**：工作区底边；**墙**：工作区左右边；**天花板**：工作区顶边
- walk 碰墙 → climb（沿墙向上）→ 到顶 → crawl（沿顶边横移，身体倒置）
- crawl 到尽头 / 被点击 → fall → 落地挤压一下 → idle 或 sit
- 拖拽：跟手，松手给一个初速度，然后 fall
- 每帧只播当前状态；切换状态时重置该状态的帧序

## 5. 没有帧素材时的降级

只有一个站立 PNG 时，引擎用「程序化近似」：

| 状态 | 近似做法 |
|---|---|
| idle | 呼吸 + 眨眼（WebGL 网格绑定） |
| walk | 水平位移 + 上下小跳 + 左右倾 |
| climb | 垂直位移 + ±6° 摆动 |
| crawl | 整体旋转 180° |
| fall | 下落 + 轻微拉伸 |
| drag | 跟手 + 悬空摆动 |
| sit | 压扁 8% |

有帧素材后，把 `assets/actions/` 放进去，引擎自动优先用帧，不再用近似。
