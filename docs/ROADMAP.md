# 路线图（ROADMAP）

约束：一个人 + AI 协作；硬件预算约 ¥500；陪伴与助手都要，但**陪伴优先**。
每个阶段都必须能独立跑起来、独立验收，不允许「等后面一起联调」。

## M0 · 桌宠壳（已完成）

透明窗口、点击穿透、托盘常驻、单实例、位置/进度持久化、视图切换、全局快捷键。

**验收**：见 `AGENTS.md` 的手工清单 1–8 全部通过。

## M1 · 会自己活着（进行中）

**已完成（B 部分，单图网格绑定）**：`src/rig.js` 用 WebGL 网格变形原图，
实现呼吸、摆动、朝鼠标倾身、瞳孔跟随、随机眨眼、点击回弹。
用 `?blink=1` / `?gaze=1` 可强制状态做视觉回归。

**已完成（A 部分，骨架）**：窗口改成整屏透明覆盖层；`src/pet.js` 实现
idle / walk / climb / crawl / fall / drag / sit / happy 状态机与边界物理
（左右墙爬墙、顶边倒挂、落地挤压、拖拽惯性）。
**待做**：逐帧动作素材（`docs/ACTIONS.md` 有 8 条生成提示词），放进
`assets/actions/<state>/` 后由帧播放器替换程序化近似。

### 原计划

- 行为状态机：`idle / happy / sleep / work / look-at-cursor`，带权重、冷却、时段（深夜变困）
- 表情层：眨眼、视线跟随鼠标、被拖动时的反应
- 空闲主动行为：每 20–45 分钟一次小动作（伸懒腰、说话），可被「别闹」降频
- 小屋时段化：白天工作、晚上休息；离开小屋时状态延续

**验收**：挂机 30 分钟，不重复同一句话；鼠标移到哪，眼睛看向哪；深夜 12 点后变困。

## M1.5 · 房间 3D 化（方向已定，暂不实现）

- 现状：2D 小屋已**移除**（用户否掉，不是想要的样子），房间留到 3D 阶段重做
- 目标：小屋改成 **3D 房间**（Three.js / WebGL），她能在里面走动、坐下、做事
- 约束：**不引入 Unity / UE**，不打包大引擎；3D 场景单独一个窗口，和桌宠共用同一份状态
- 顺序：等 M2 语音和 M3 记忆稳定后再动，避免 3D 返工

## M2 · 语音闭环（3–4 周）

`唤醒词 → ASR → LLM → TTS`，支持打断（barge-in），延迟目标 < 800ms。

- 技术选型：sherpa-onnx（ASR）+ edge-tts（TTS）+ 本地 Ollama 或云 API
- 常驻独立进程（后续 `services/core`），桌面端只负责音频采集与播放
- 无网时降级：只做本地口令响应，不报错

**验收**：说「小鱼」→ 她应答；说话时插话能打断；断网时仍能回应「在呢」。

## M3 · 记忆 v1（2–3 周）

- SQLite 事件流（`event` 表）+ 每天一次摘要固化（`summary` 表）+ 向量召回（sqlite-vec）
- 记忆分三层：事件（发生了什么）/ 事实（关于你）/ 情感（当时什么感觉）
- 对外只暴露 `recall(query, k)` 与 `remember(event)` 两个接口

**验收**：隔天问她「我昨天让你记的事」，能答对；重启后记忆不丢。

## M4 · 助手能力 L0 / L1（3–4 周）

先只做 5 个安全动作：查电量/网速/磁盘、开指定应用、调音量、整理下载文件夹（可撤销）。

- 每个动作一个 schema + 一句人话描述 + 撤销实现
- L2 以上（删文件、关机）只做「确认气泡」骨架，不接真实执行
- 所有动作写审计日志，用户可查

**验收**：说「帮我看看磁盘」→ 她答数值；说「把音量调到 30」→ 确实变了且有撤销。

## M5 · 视频形态（3–4 周）

- 摄像头 → MediaPipe FaceLandmarker（本地）→ 驱动 Live2D 的眼与头
- 口型用音频包络驱动；通话界面独立窗口，可缩小为画中画
- 明确的「摄像头使用中」指示与一键关闭

**验收**：你转头，她的眼睛跟着转；说话时嘴型跟得上；关闭后摄像头指示灯灭。

## M6 · 机器人 v0（6–10 周）

- 硬件：ESP32-S3 + 1.28" 圆屏（双眼）+ 2 自由度云台 + 电容摸头 + I2S 麦克风 + 喇叭（BOM 见 README）
- 固件只做：显示眼睛、舵机、触摸上报、音频收发；**不做本地推理**
- 局域网 WebSocket 连 PC 的 core；PC 做人脸检测并回传注视点
- 断连时：进入「自己发呆」模式，不僵死

**验收**：手机热点下也能连上；摸头有反应；你走动时她的头会转过来；延迟 < 300ms。

## M7 · 手机端（4–6 周，先 PWA）

- PWA + 局域网直连（后续再考虑原生/上架）
- 「在场权」：同一时刻只有一个主形态，切换时带走情绪 + 最近 N 条记忆
- 能遥控机器人做 3 个动作（点头、摇头、看这边）

**验收**：手机上点「带走她」→ 桌面收起，手机显示同一角色且记得刚才聊的话。
