# 桌宠项目

这是同一角色陪伴系统的第一阶段：先完成 Windows 桌面上的 Q 版桌宠原型。

## 当前原型

- 无边框、透明、置顶的桌面窗口
- 点击角色可触发不同回应
- 右键打开她的小屋，按“回到桌面”或 Esc 返回
- 角色素材由 HTML、CSS 和内嵌 SVG 绘制

## 本地运行

需要安装 Node.js 当前 LTS 版本。

    npm install
    npm start

## 交互

- 左键点击角色：回应并切换情绪
- 右键：打开小屋
- 小屋返回按钮或按 Esc：返回桌面
- 顶部细条：拖动窗口
- 右上角 ×：关闭程序

语音、共享记忆、电脑操作授权、视频形态、手机控制和实体机器人会在后续阶段逐项加入。
